One image summing up the world's news of Tuesday 24 November 2026: 36 stories
across 7 regions, built as a newspaper front page — masthead, lead story, 11
photo cards and a region-by-region list of the rest of the day.

Lead: Nvidia's board unanimously reinstates Jensen Huang as chief executive,
11 days after he resigned. Around it: Ukraine sinking a Russian warship off
Libya, COP31 collapsing over fossil fuels, Iran's Gulf strikes, a Russian drone
straying into Polish airspace, Spain's election, Gaza, Mexico's capture of
'El Chapo Isidro', Panama's Cobre mine talks, the Pope's South America tour,
a deadly boat capsizing in Nigeria, and Australia's 5%-of-revenue tech fines.

Every photo is a real photograph of the event or subject, from Wikimedia
Commons (public domain / CC). The program itself needs no network: it copies
the bundled `entry.png` to `/output/entry.png`, deterministically.

## Run

```sh
node main.ts
```

Writes `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
